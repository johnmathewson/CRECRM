How it works

  • Open a CREXi listing page → click the extension icon → "Sync this listing."
  • Same for LoopNet.
  • Auto-sync runs every 6 hours when those tabs are open.
  • The CRM matches by listing ID — make sure each property's CREXi/LoopNet URL is saved in the CRM first.
